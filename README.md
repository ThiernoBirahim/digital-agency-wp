# Projet de Création d'Agence Digitale - WordPress

Ce projet a été réalisé dans le cadre de l'examen final de Gestion de Contenu (CMS). Il consiste en la mise en place complète d'un site web pour une agence digitale, incluant la configuration, l'optimisation et la sécurisation.

##  Fonctionnalités implémentées
- **Thème utilisé :** Astra (Personnalisé avec Elementor(excuise moi pour ne pas metre gutenberg apres je vai modifier))
- **Optimisation des images :** Utilisation de **Smush** pour réduire le poids des médias et améliorer le temps de chargement.
- **Sécurité :** Installation et configuration de **Wordfence Security** (Protection contre les attaques Brute Force limitée à 5 tentatives).
- **Sauvegarde :** Configuration d'**UpdraftPlus** pour des sauvegardes hebdomadaires automatiques.

## 📂 Structure du dépôt
- `/theme` : Contient les fichiers du thème Astra utilisé pour le site.
- `/screenshots` : Contient les preuves de configuration demandées :
  - `security_scan.png` : Preuve du scan de sécurité.
  - `optimization.png` : Résultat de la compression des images.
  - `backup_success.png` : Planification des sauvegardes.

## 🛠️ Installation
1. Installer un environnement local (MAMP).
2. Importer la base de données via PHPMyAdmin.
3. Placer le dossier du thème dans `wp-content/themes/`.
4. Activer les extensions recommandées (Wordfence, Smush, UpdraftPlus).
